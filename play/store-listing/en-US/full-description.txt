APK Extractor exports the APK files already installed on your device, including every installed split. It is completely free, ad-free, and open source, with no root or Internet permission.

Tap an app to extract it, or long-press to select and export several apps at once. Conventional installations are saved as individual APK files. Apps installed from multiple APK splits are saved as ZIP archives containing the base APK, every installed split, and a manifest with filenames, split names, sizes, and SHA-256 hashes.
Split APK ZIPs are archives, not individual installable APK files; to reinstall one, extract all of its APKs and use a split-APK installer that installs them together.

Features
• Browse user apps, system apps, or every installed app
• Search by app name or package name
• Extract one app with a tap
• Select and extract multiple apps concurrently
• See individual progress for every export
• Finish exports in the background with native progress notifications
• Share completed exports directly from the app or notification
• Choose any destination supported by Android’s system folder picker
• Automatic light, dark, and dynamic color themes
• Adaptive layouts for phones, tablets, foldables, and desktop windows
• Mouse hover, right-click menus, and visible keyboard focus
• Ctrl/Cmd-click to select apps and Shift-click to select a range
• Keyboard shortcuts for search, selection, extraction, and context menus
• Export folder and last result alongside the app list in wide desktop windows
• Multiple desktop windows with independent search and selection
• Drag exported files or completed batches to other apps that accept file drops

Open source
Read the code, report an issue, or contribute at:

APK Extractor uses broad installed-app visibility solely because displaying and exporting any installed app is its core and only purpose. Installed-app information is processed locally and never leaves your device.

Exported files contain the APKs installed for your current device. Split APK archives may be specific to its processor, display density, languages, and installed features. They do not contain the app’s user data and are not the publisher’s original Android App Bundle. Third-party apps remain the property of their respective publishers and should not be redistributed without permission.
