## Permissions

- `QUERY_ALL_PACKAGES`: App functionality. APK Extractor is a file-management utility whose core feature lists every installed user and system app so the user can choose one or more packages and export their base and split APK files. Broad package visibility is required because a user may need to extract any installed package, not only packages known in advance.
- `POST_NOTIFICATIONS`: Used for user-initiated extraction progress and completion
- `POST_PROMOTED_NOTIFICATIONS`: Requests eligible native promoted ongoing progress on supported Android versions
- `FOREGROUND_SERVICE_DATA_SYNC`: Local processing — Importing, exporting. Used only for user-initiated APK exports.
- Reviewer video for both declarations: https://apk.kole.work/review/apk-extractor-permissions.mp4
