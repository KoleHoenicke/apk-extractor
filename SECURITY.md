# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability.

Use GitHub's private vulnerability reporting for this repository so details can be reviewed before disclosure. Include the affected Android version, reproduction steps, expected impact, and any proof of concept that is safe to share.

Ordinary functional bugs and compatibility problems can use the public issue tracker.

## Supported versions

Security fixes are made against the latest source and the current Play Store release. Users should update to the newest available version.
